# Security policy

## Pre-release status

Lace is pre-release software. No Lace version is currently designated as
security-supported, and the project makes no response-time or remediation-time
commitment.

## Reporting a vulnerability

Until the project publishes a project-owned security contact, report suspected
vulnerabilities through this private reporting placeholder:

> **Private reporting channel: to be established before the first public release.**

Do not open a public issue, publish exploit details, or otherwise disclose a
suspected vulnerability before the project has acknowledged the report and the
reporter and maintainers have coordinated disclosure.

## Report contents

Include a description of the issue, affected commit or version, reproduction
steps or proof of concept, impact assessment, and any suggested mitigation.
Avoid including credentials, personal data, or production secrets.

## Policy updates

Before the first public release, maintainers MUST replace the placeholder with a
private project-owned reporting channel and state the supported-version policy.
